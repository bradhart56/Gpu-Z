## 📘 About

GPU-Z is a compact diagnostic tool built by TechPowerUp for people who want a clear read on what their graphics hardware is actually doing. It reports the exact GPU variant, BIOS version, bus interface, memory size and bandwidth, clock frequencies and supported DirectX and Vulkan feature levels. The sensors tab keeps a rolling log of core and memory clocks, GPU load, temperatures, fan speed and power draw, which is useful when you are checking whether a card is boosting correctly or whether a laptop is thermally throttling. Recent builds add support for the newest consumer and workstation cards as they ship, along with minor UI refinements and an updated validation backend.

If you came looking for a GPU-Z download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes.

**Good for:** PC builders verifying a new GPU · laptop owners checking thermal throttling · overclockers monitoring live clocks · repair technicians diagnosing faulty cards · buyers validating a second hand GPU · enthusiasts comparing BIOS revisions · support staff collecting hardware reports.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Sensor readings stay blank | Close other hardware monitoring tools that may hold the sensor driver. |
| Wrong GPU name shown | Update the app to the latest build so the card database is current. |
| Temperatures look too high | Check fan curves and case airflow, then re read the sensors tab. |
| App will not start | Run it as administrator once, then launch normally. |
| Laptop shows two GPUs | Switch the power profile to High performance to wake the discrete card. |
| Report upload fails | Verify your network connection and retry the validation step. |
